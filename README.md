## ➕ How to Add a Link

**Adding a link to an existing section** — copy this row and paste it at the bottom of the section's table:

```markdown
| [Website Name](https://example.com) | Short one-line description | 🆓 |
```

**Adding a brand-new section** — copy this block, paste it above this "How to Add" section, then add it to the Table of Contents:

```markdown
## 🎯 New Topic Name

| Website | Description | Tag |
|:--------|:------------|:---:|
| [Website Name](https://example.com) | Short one-line description | 🆓 |

<p align="right"><a href="#-awesome-web-vault">⬆️ Back to top</a></p>

---
```

> 💡 **Tips**
> - Keep descriptions under ~10 words so the tables stay tidy.
> - Mark your absolute favorites with ⭐ so they stand out.
> - Table of Contents link format: `[Topic Name](#-topic-name)` — lowercase, spaces become `-`, symbols like `&` are dropped.
